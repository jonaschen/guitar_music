## 本段完成

- 新分析明確傳入 `melody_mode=off`，跳過分離、音高偵測、旋律後處理與旋律音檔。既有旋律資料保留；保存／JSON 備份不刪除它，伴奏 MIDI 排除旋律。
- 首頁、分析中、歌曲頁三種主要狀態。首頁貼網址即時檢查，失敗用白話說明；新分析失敗保留舊工作譜。
- 歌曲頁每行四小節、連續小節號、文字和弦；一般點擊從該處播放，進入編輯模式才修改。
- 第一層：和弦譜、播放／暫停、聲音、調性與 Capo。第二層：循環、吉他練習速度、編輯、復原／重做、下載。第三層：版本歷史、還原原始分析與診斷。
- 修改停止 1.2 秒後自動建立新修訂，不覆寫原分析或父修訂；保存失敗保留頁面修改、提示重試與離頁提醒。歷史顯示同一工作譜最近 50 個修訂。
- 保留四種字級、8px 間距、單一主表面；移除裝飾光暈；主色用於播放與目前小節，互動過渡 200ms，尊重減少動畫偏好。
- 網頁 API 改為同源 `/backend` 代理，不再讓手機請求自己的 localhost:8000。已開本機區網預覽，未部署公共網站。

## 已知限制

- 手機為響應式瀏覽器版本，尚未實機驗收 iOS／Android；不是原生 App，也不保證離線使用。
- 原曲合奏維持 100% 原速。速度調整目前只提供吉他練習，避免原曲變速造成變調後和吉他音高不合。
- 自動保存仍需本機服務；收到失敗提示時不可當作已保存。原始分析還原需要來源 job 仍保留；編輯復原／重做保留最近 50 步。
- 已保存舊譜的標題、原始辨識結果與聲音品質沒有因 UI 改版而改善。沒有宣稱旋律或新歌曲品質通過。
- 完整歷史工具仍保留在第三層；後續可依實際需要繼續刪減，不讓它成為主流程依賴。

## UI 驗收回饋與拍長修正

使用者確認播放／點和弦定位、調性／Capo、和弦改名／復原三項沒有問題；另回報拍長修改無法成功。

根因：舊時間編輯禁止與相鄰和弦重疊，拖曳上限也固定在下一和弦起點，延長相連和弦因此被擋住。簡潔編輯區原本只有改名，沒有直接調整拍長的入口。

修正：簡潔編輯區新增目前拍長與增加／減少半拍。依實際拍點間隔插值，相連和弦共用的交界一起移動；已有休止不搬動下一和弦，不刪除和弦，不跨越其他事件。保留至少 0.1 秒，超出歌曲／鄰接範圍時白話提示並保留原譜。進階秒數與拖曳沿用同一套相鄰邊界邏輯。一次復原／重做涵蓋兩個受影響和弦，播放停止後重新編譯，自動保存保留原始分析。

驗證：產品套件 12 項通過，包含新增變速拍格、休止／邊界保護及拍長→自動保存→播放輸入→復原／重做檢查。進階時間控制另驗證拖曳範圍與秒數套用；build 通過。

只待拍長操作人類驗收，不再重測前述已通過三項。

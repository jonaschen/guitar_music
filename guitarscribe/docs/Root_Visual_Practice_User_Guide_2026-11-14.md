# GuitarScribe 低頻與根音行進練習使用說明

2026-11-17 新增「歌曲大段」篩選及「整理歌曲結構」，可先選主歌／副歌再練根音。見[歌曲結構使用說明](Song_Structure_User_Guide_2026-11-17.md)。

從原本主畫面可直接按「視覺化練習」。已開啟歌曲時會帶入同一首歌；空白首頁則進入選歌／匯入頁。若看不到新按鈕，請重新整理。

適用於 2026-11-14 視覺練習入口。這套工具協助你反覆聽一小段音樂、觀察低頻線索、比較參考音，再保存自己的根音判斷。

## 開啟歌曲

在運行 GuitarScribe 的電腦，用瀏覽器開啟下列連結，沿用原本的邀請帳密：

- [膽小鬼](http://localhost:5273/visual-practice-2026-11-14/?practice=roots&visual=1&job=83a3643ab3814172a046cebf709f3413)
- [沒那麼簡單](http://localhost:5273/visual-practice-2026-11-14/?practice=roots&visual=1&job=a3be29912a7045448765290d7cba2f6c)
- [匯入其他歌曲](http://localhost:5273/visual-practice-2026-11-14/?practice=roots&visual=1)

其他歌曲可貼上 YouTube 網址或選取本機音檔，再按「開始分析」。完成後若停在和弦頁，按「根音抓歌練習」。YouTube 能否取得音訊仍取決於既有匯入流程；無法取得時，可改用你已有的本機音檔。

`localhost` 指目前開啟瀏覽器的電腦；把這個網址貼到手機，不會自動連到家中電腦。

## 第一次練習

1. 找到「看著音樂抓行進」。若內容折收，按「開啟視覺化」。
2. 按「產生低頻圖」，等狀態顯示「低頻圖已就緒」。生成後可看到低頻亮線及原分析和弦。
3. 按「看 10 秒」。在上方低頻圖中左右拖曳，選出一段約 2–5 秒的 A–B 範圍；A 開始、B 結束會直接標在圖上，時間顯示在圖上方。
4. 在主要播放列按「播放原曲範圍」，只聽原曲本身。即使已有採用的根音，也不會加入合成根音或和弦聲。按「暫停播放」停止；「循環原曲範圍」可開關循環。
5. 在頻譜點選位置，或用方向鍵移動游標，右側會自動切到對應段落與參考音。游標保留在你點選的秒數，A–B 與目前縮放保持不變。若想整段回聽，按「以目前段落設定 A–B」。**拖曳框選仍只設定回聽範圍，不會批次採用或重切段落。**
6. 在參考音區點選音名，或展開「其他音（Eb2–Eb3）」，用「低半音／高半音」逐步比較。可調整原曲及根音音量，避免參考音蓋過歌曲。選音會開始試聽，但還沒保存。
7. 查看採用鈕旁的「將記錄到」段落與起訖，確認試聽音後按「採用這個根音」。仍無法判斷時按「還聽不出來」。確認頁面上方顯示「已保存」。
8. 按「下一段」繼續；尚未採用的試聽音不會帶到下一段。也可拖曳較長 A–B 聽前後行進。若想加入自己採用的合成根音，明確按「回顧我的行進（含已採用根音）」。採用本身不會自動跳段。

建議先完成兩個相鄰區段。先聽低音如何移動，再聽上方和聲是否支持你的根音判斷，不必一次填完整首。

## 主要畫面與進階工具

主畫面保留根音區段、主要播放、低頻圖與目前判斷。桌面上圖與判斷區並排，手機上下排列。主要播放列分別標示原曲 A–B 與實際正在播放的範圍；主動試音時會顯示「比較音」。

主要播放列會固定在畫面上方，捲到採用區也能回聽與暫停。若節拍聲已開啟，聲音狀態會顯示「＋節拍聲」；可展開工具，在「節拍與小節對齊」關閉「播放時加入節拍聲」。

「練習設定與進階工具」預設折收；BPM、小節對齊、分段、精確秒數與舊有播放選項都在裡面。展開偏好會在本分頁保留，收合不會停止正在播放的音訊或重新計算頻譜。保存錯誤及拍格需要套用的提示仍留在主畫面。

## A–B 範圍怎麼標

**A 是開始，B 是結束。** 例如 A = 0:10、B = 0:15，就是只聽第 10 到 15 秒。

最直接的方法：在低頻圖上按住滑鼠，從想開始的位置拖到想結束的位置，再放開。反向拖曳也可以，較早的時間會是 A；觸控螢幕可左右拖曳。

不想拖曳時，可以分兩次點選：

1. 點圖上的開始位置，再按「游標設為 A（開始）」。
2. 點圖上的結束位置，再按「游標設為 B（結束）」。
3. 核對上方 A／B 秒數，按「播放原曲範圍」。「A–B 循環」勾選時會反覆播放。

若新 A 超過舊 B，B 會暫設歌曲結尾，畫面會提醒你再設 B；若新 B 早於舊 A，A 會暫設歌曲開頭。起終點至少相隔 0.08 秒。A/B 超出目前可見時間窗時，仍可看上方秒數，或按「放大 A–B」看完整選區。

只想聽右側正在判斷的整段，按「以目前段落設定 A–B」。跨段拖曳後，這個按鈕仍使用**右側選定段落**，不會因播放游標落在另一段而選錯。設定 A–B 不會修改根音判斷。

## 放大圖與時間範圍

圖的高度預設 **2 倍**；用「圖的高度」可選 1、2、3、4 倍，本分頁重新整理會記住選擇。桌面也擴大圖的可用寬度，右側保留判斷區。手機依螢幕寬度上下排列，可垂直捲動大圖。

要同時看更長的行進，選「看 60 秒」或「看 120 秒」；要看細節，選「看 10 秒」或「放大 A–B」。圖變大不會提高原音訊或頻譜分析本身的解析度。

## 三個圖層怎麼看

| 圖層 | 表示什麼 | 判讀方式 |
| --- | --- | --- |
| 低頻頻譜 E1–E4 | 原曲混音在各頻率的能量，橫向為時間，縱向為音高刻度 | 較亮代表能量較強；亮線可能是基音、泛音或鼓聲，不能直接當根音答案。 |
| 原分析和弦 | 自動分析提供的和弦及區間 | 用來提出待核對的猜測，可能有錯音、漏換和弦或換音時間不準。 |
| 我的根音行進 | 你明確採用的 C–B 音級 | 待聽區域不補音。圖中高低是音級排列，沒有原曲八度，不能當成真實貝斯高低走向。 |

例如 C/E 的和弦根音是 C，最低音是 E。如果正在練習抓低音，可以先聽出 E，再檢查上方和聲；本頁「採用這個根音」保存的是和聲根音 C，目前沒有另外保存獨立低音聲部的欄位。

頻譜使用約 0.74 秒的時間窗，快速換音會被展寬；不要用亮線邊緣決定非常精細的換音時刻。試聽音使用合成音色，與錄音中的吉他或貝斯音色可能不同。

## 定位與播放

| 操作 | 結果 |
| --- | --- |
| 點低頻圖 | 移動播放位置、停止目前播放，右側同步到該時間所屬段落；不改保存稿。 |
| 在低頻圖左右拖曳 | 設定 A–B，停止目前播放；不改根音分段。 |
| 看 10／30／60／120 秒 | 以目前位置附近為中心縮放。 |
| 看全曲／往前看／往後看 | 改變可見範圍，不改原分析。 |
| 放大 A–B | 讓選取的播放範圍充滿圖表。 |
| 以目前段落設定 A–B | 把回聽範圍對齊右側目前判斷段落，不改根音稿。 |
| 播放原曲範圍 | 播放 A–B，依「循環原曲範圍」設定循環；原曲沒有額外根音。 |
| 點原分析和弦或已採用根音方塊 | 選該方塊的時間範圍並定位，右側同步到起點所屬段落；不採用或更改音名。 |
| 顯示較弱線索 | 調整顯示強弱範圍，不改音量或分析結果。 |

圖表取得鍵盤焦點後，左右鍵移動 0.1 秒並同步右側段落；按住 Shift 移動 1 秒；Home／End 移到目前可見範圍的起／終點附近。

展開「練習設定與進階工具」後，「選擇播放範圍」可以用 A／B 滑桿或秒數輸入。**A–B 只決定播放哪一段，不會把該範圍變成新的根音區段。** 裁切分析的時間以本片段 0 秒開始，畫面會提示對應原錄音的位置，不需再自行加偏移。

主要播放只聽原曲；需要明確試音時點音名。進階工具展開時也保留「循環 A–B 原曲」與「聽目前圖中範圍」兩個圖表快捷鍵，這兩個明示循環的功能會啟用循環。原曲範圍暫停後續播仍只播原曲。先前正在響的單音試聽會在開始圖表播放時停止。圖上的已採用根音仍保留顯示，這不表示它正在發聲。

## 依小節練習

先展開「練習設定與進階工具」，再於「節拍與小節對齊」設定 BPM、每小節拍數及小節起點，先回聽確認格線是否對齊。這是手動設定，軟體不會因你輸入 BPM 就知道拍號或第一拍。

若希望根音段落跟著小節走，使用「預覽小節分段」或「只按整小節重排」，檢查提案後再按「套用這份分段」。這一步會改練習稿；只調整格線或 A–B 不會重切根音段落。採用鍵若因拍格尚未套用而停用，主畫面會提示；按「調整並套用拍格」展開工具，完成分段預覽與套用。

一小節內確實換根音時，再用「半小節一段」或「四分之一小節一段」。原判斷衝突的區域會留待確認，請回聽；固定 BPM 的格線無法完整追隨變速錄音。

## 保存與備份

看圖、縮放、選 A–B、試聽不修改已保存的根音判斷。「採用這個根音」「還聽不出來」、套用分段、復原及還原備份會改練習稿。

進度會自動保存，請留意頁面上方保存狀態。新視覺入口與原根音入口使用同一首歌的同一份練習稿；受邀者亦共用該空間。

在「進度與備份」可用：

- 「下載完整練習」：保存根音練習 JSON，之後可還原；不含原曲音訊。
- 「下載根音行進文字」：取得方便閱讀的時間與音名。
- 「還原同曲備份」：載入相同來源的練習，會改目前練習稿。

若出現保存衝突或離線問題，先下載需要保留的草稿，再重試或載入最新版本；不要把「載入最新版本」當成保存本頁尚未送出的內容。

在「歷次保存」按「預覽恢復版本」時，工具區會自動展開，讓你先檢查分段預覽再決定套用。

本頁的原分析和弦是參考層，根音採用不會改和弦名稱。要修改和弦請按「返回和弦頁」，在原有和弦核對功能操作；目前沒有完成獨立的和弦品質／組成音練習流程。

## 常見問題

| 現象 | 處理方式 |
| --- | --- |
| 我的根音行進仍是空白或斜線 | 試聽不等於採用；在正確段落按「採用這個根音」後才會畫出。 |
| 三個參考音都不合 | 展開「其他音（Eb2–Eb3）」比較，或保留「還聽不出來」；候選並不保證含正確答案。 |
| 按圖表循環只聽到原曲 | 這是低頻聽辨的正常行為，已採用根音也不加入播放。要主動比較單音請到參考音區試聽。 |
| 聽不到聲音 | 檢查系統、分頁與頁面音量，確認已按播放且沒有音訊錯誤訊息。若原曲無法取得，可回單段練習選「根音」比較參考音。 |
| 看不清亮線 | 先縮至 10 秒，再調「顯示較弱線索」。混音本身可能沒有清楚的低頻線，不必強行找答案。 |
| 顯示來源無法核對，和弦層被隱藏 | 重新開啟歌曲後再生成。頻譜可能仍可看；不要把隱藏和弦理解為原曲沒有和弦。 |
| 音訊無法取得或長度不符 | 重新載入歌曲確認來源；需要時重新匯入。原有已保存根音仍可備份。 |
| 歌曲太長或音檔太大 | 此視圖上限為 20 分鐘與 160 MB，改為分析較短片段。 |

## 已驗證的範圍

2026-11-14 操作整理後的完整根音測試 41 項通過，最後游標文字標示另作相關重查，包含已知音高、反相聲道、靜音、選段、播放、保存、來源不符及取消後的舊回覆隔離。另用《膽小鬼》《沒那麼簡單》的實際音訊檢查頻譜、和弦顯示、選段、播放位置，以及 320／390／768／1440 像素寬度；沒有頁面例外或非預期寫入，兩首既有分析與根音稿保持相同。

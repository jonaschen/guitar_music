## 問題與證據

主旋律不等同人聲。使用者確認分析時間 220–233 秒的旋律在伴奏軌、聽似小提琴；人聲 C／G 皆無法辨認該段。自製頻譜路徑 I1／I2 也均未通過，停止在該方案上微調。

## 本次迭代範圍（P0）

- 比較既有 predominant-melody 方法或更細分離，隔離 benchmark 依賴與授權。
- 固定同一來源、時間、合成器，保留參數／版本／原始音高。
- 先做短片段，不能把伴奏直接交給單音人聲流程或最高音選取當成主旋律。
- 明確記錄 voice / instrument / unknown 區段來源；此次只用使用者確認區段，不宣稱自動判斷完成。

## 驗收

- [x] 至少一個既有方法完成可重現短片段 benchmark（MELODIA 隔離實驗；聽感尚未通過）。
- [ ] 使用者能辨認候選跟隨原伴奏中的主旋律；失敗也必須記錄。
- [ ] 以其他器樂段落驗證，不將單段成功視為全曲通過。
- [ ] 採用前完成依賴／授權檢查，正式 worker 與預設分析不被試驗污染。

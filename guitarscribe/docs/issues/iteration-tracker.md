## 目標

準確且充分的歌曲分析 → 可比較／可編輯初稿 → 原曲對照 → 保存與忠實匯出。維持品質 gate，不以功能完成百分比取代聽感驗收。

## 本輪工作看板

- **未解決、暫停實驗 / P0**：#2 器樂主旋律：O 音訊清楚，但 O／N 辨識仍只有部分區段接近。使用者同意停止反覆參數／來源 A/B，保留缺陷，不部署失敗候選。
- **進行中 / P1**：#3 共享时间軸：新增 2–8 完整小節的分界預覽／校正、首尾固定、不移動音符與和弦。Bar 30–31 實曲合奏驗收未過。
- **進行中 / P1**：#4 優先可用的原曲對照、人工修譜、Undo／Redo、獨立保存重載。候選比較與完整八小節流程尚未完成，不覆蓋人工編輯。
- **持續 / P1**：#5 跨段落／跨歌曲品質驗收與回饋追蹤。

## 迭代規則

一次只推進一個主要辨識假設；可重現來源與參數；工程測試後才發短片段人工測試。有改善才擴段／整合；無改善記錄結果並停止該分支。不將外部模型直接變成正式預設，不擅自覆寫修訂。

每次 checkpoint 更新對應 issue：commit、測試、使用者結果、下一步及停止條件。待使用者聽感是驗收狀態，不假裝完成，也不重複產生等價試聽檔。

## 本轮測試目標

八小節編輯中的分界校正是否容易操作，修改是否可撤銷並保存重載；確認和弦／旋律秒數保留。先驗證人工修譜的實用性，不再要求聽等價旋律候選。仍需後續實曲確認小節位置與合奏，不將工程測試當成音樂正確性驗收。

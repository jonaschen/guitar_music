## 問題（P1）

G 候選在多段接近來源 C，但目前只存在診斷／獨立譜；尚無安全的候選比較、接受與編輯入口。整首 1059 音符可映射弦格並匯出，不等於可讀性或 UI 驗收完成。

## 範圍

把已驗證候選接入「對照原曲 → 選段 → 明確接受 → 改音 → 重播 → 獨立保存」；不要繼續堆疊大量診斷按鈕。原分析、使用者修訂與未知區段必須可區分。

## 驗收

- [ ] 顯示候選來源、參數、區段與未驗收狀態。
- [ ] 接受候選為新分支，不覆蓋人工修訂；可取消、Undo、重載。
- [ ] 修譜、播放、匯出使用同一份確認後資料。
- [ ] G 的短音／休止保持；可讀譜簡化不能靜默改變播放旋律。
- [ ] 完成一次使用者的選段改音與保存回放測試。

來源候選仍失敗的段落不自動填入正式樂譜。人聲細解析度只有「略好」回饋，尚不是正式預設。

## 本輪工作先固定

1. 移除 runtime 的速度連續性重試。保留final0原DBN及原引擎成功即返回的保護；不啟用全域新引擎。用固定15錄音既有快取核對新的runtime只對應原DBN，已拒絕continuity不會再被選入。
2. 可聽性修正：同一時間、音符及混音基準，提供原曲降低6dB的輔助版、A/B各自的吉他獨聽／click獨聽。原PCM與判決不變。不要求重測已拒絕或已接受片段；音量工具不構成音樂品質改善。
3. 和弦診斷只讀：固定第三組A的整個24–64秒，特別列出播放器18–24秒。比較每次實際刷到的和弦音集合、延音期間譜上和弦，以及小節第一拍的片段佔比。不換和弦、不移拍點、不新增試聽。
4. 同一診斷套用原批次其他具有結構可用拍格的資料；原拍格有效者保留，否則只用final0原DBN工程候選，排除已拒絕連續性。這只能回答播放器與現有偵測稿是否一致，不能推論哪個和弦符合錄音。

停止／接續：若只發現原偵測稿與演奏不一致，先定位是哪一層，不用多數時長或調內和弦當真值。沒有獨立和聲證據，不手改Gm6、Abmaj7等名稱來做比較。這輪不重新要求使用者聽同份素材。

# 手機現場介紹：故事地圖與執行紀錄

使用者明確選擇「用自己的手機現場示範給朋友看」。本輪交付這條完整流程，沿用既有登入與歌曲，不引入朋友帳號或多使用者隔離。

| 順序 | 活動／使用者故事 | 驗收重點 |
| --- | --- | --- |
| MD1 | 我能從手機開啟受保護的現有歌曲 | HTTPS、匿名拒絕、原登入可用、原曲 Range 支援 |
| MD2 | 我能用歌曲大段介紹練習方法 | 保存稿優先、ready 初稿可展示但不自動套用、確認狀態明確 |
| MD3 | 我能點一段立即回聽原曲 | 觸控當下啟動播放、片段內時間、A–B 循環、切段／背景停播 |
| MD4 | 我能展示低頻線條與已採用根音 | 觸控 A/B、窄螢幕無橫向溢出、沒有合成音、不寫稿 |
| MD5 | 我能從原畫面進入介紹並回到練習 | 當前歌曲連結、重新整理保留入口、複製連結不含憑證 |
| MD6 | 我能依簡短說明完成現場示範 | 三分鐘步驟、事先載入、主機與臨時入口限制清楚 |

故事地圖：**準備連線 → 選歌曲與大段 → 回聽 → 看低頻 → 結束／回到練習**。MD1–MD6 依此排序實作；保留原有練習資料與入口。

測試以可重現的來源與狀態保護為核心：先建立失敗案例，再補實作。A–B 循環先驗證介面不存在而失敗，再加入循環與結束停止行為。模型標籤正確性與實體手機主觀操作體驗不以模擬測試代替。

完成狀態、測試數值與實際發布驗證見本文件後續紀錄；操作說明見 [使用手冊](Mobile_Demo_User_Guide_2026-11-17.md)。

# 分析前略過 MV 開場（2026-10-02）

本 checkpoint 取代先前「分析完整原檔後才限制範圍」的測試流程。上傳與 YouTube 分析均可設定 `skip_seconds`（預設 0）。

## 使用者測試

1. 保存現有修改，再重新整理頁面。
2. 選擇原始 MV 音訊，在「分析前略過開頭（秒）」填 `19`，再按 Start analysis。
3. 分析完成後，確認提示「樂譜／播放 0 秒 = 原檔 19 秒」。例如原檔約 20 秒的第一個前奏音，在新時間軸約 1 秒；不要再重複略過 19 秒。
4. 對照來源音訊確認開頭，再以 Melody editor 選 4 或 8 小節，播放、暫停、編輯音符、重播。最後 Save new revision。
5. 若開頭裁掉歌曲，需用較小的略過秒數重新分析；取消分析後的「歌曲有效範圍」不會補回沒有分析的開場。

## 時間與資料契約

- 原始上傳／下載檔案不覆寫；建立 `analysis-source.wav` 作為分析、原音訊播放的共同來源。
- 在節拍、和弦、分離與旋律辨識前裁切。因此樂譜、診斷音訊、候選資料、MIDI／MusicXML 都是裁切後的零起點時間，不另加 19 秒空白。
- `song.source_start_seconds` 保存原檔時間偏移：原檔時間 = 分析時間 + 偏移。修訂与 JSON 保留此欄位；既有譜預設偏移為 0。
- 起點不強制視為第一拍，拍點／小節仍由分析產生，音樂上的對齊仍需人工檢查。
- 分析後的「歌曲有效範圍」依然只是限定播放與主要譜面；它不會再裁切完整工作譜匯出。
- 負數、非有限數拒絕；起點達到／超過片長時分析失敗並提示縮短略過秒數。裁切支援取消與 120 秒逾時。
- 不承諾改善旋律辨識準確度；本次改動只確保非歌曲開場不參與分析，且資料／音訊使用同一個時間基準。

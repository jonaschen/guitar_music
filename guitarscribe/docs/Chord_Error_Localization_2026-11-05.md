## 分類與判讀規則

逐區間採互斥優先序：參考未知 → 預測未知 → 正確休止／漏和弦／多和弦 → 錯根音 → 根音相同但種類／省略音不同 → 僅低音不同 → 完全符合診斷音集合與低音。全部類別秒數之和等於片段時長。缺參考填 X、不算休止；預測空隙填 N 並保留 gap 來源。預測 X 在已知參考內計入未匹配秒數，不能當正確。相同音高的異名可等價正規化，斜線低音與省略音保留。

`same_root_wrong_quality` 是嚴格標籤／理論音集合差異，不是已證實的聽感錯誤。例如 power chord 對 major、`C:7(*5)` 對 `C:7` 都會落在這欄。`exact_match` 同樣不代表已通過人耳。Root／majmin 保留原評分器的投影；詞彙外參考從 majmin 分母排除，不能把小覆蓋的高分當整段正確。

## 支持與不支持的結論

錯根音出現在和弦內部，不只換和弦附近。以下「內部」排除所有參考切換點 ±250ms 的聯集；這是定位指標，不能單憑距離證明錯誤成因。其他三欄為重疊旁註，**不可相加，也不抵銷原始錯誤**。

Funk2 內部錯根音 18.707s；HU33 04／18／21 分別 7.863／8.227／9.395s。因此僅整理短邊界不足以解決現有持續根音差異。HU33 04 的 18.855–20.341s 為 `B:hdim7/b3` → `D:min`；HU33 21 的 8.359–11.424s 為 `C:maj` → `F:maj`。前者含轉位／和弦內音歧義，後者不能直接以同音集合免責。這些都未直接試聽確認。

對省略音、轉位與同音集合，只報可能機制，不宣稱兩者聽感或功能相同，不提高主要分數。現有資料仍無法把問題完整分成聲學辨識、字典限制、低音偏重與序列解碼責任；本段未發現可直接修正的產品工程缺陷。

## 唯一下一項機制與停止條件（提案，未執行）

假說：Chordino 根音選擇對 bass chroma 的相似度貢獻，可能在轉位／省略根音與和弦內音佔優時把其他和弦內音選為根音。依據是 HU33 與 Funk2 大量持續內部錯根音，以及錯根音中常見參考和弦內音；這仍非因果證明。本機已用版本的 `Chordino.cpp` 在局部和弦相似度分別加總 bass 0–11 與 treble 12–23 bins，提供直接可消融的單一機制。

建議下一段只做 **bass 相似度貢獻 1 → 0** 的固定消融，保留 treble、字典、正規化、NNLS、時間與 HMM 其他規則；明列此消融也會影響整體 salience，不能解讀成獨立校準的根音估計器。不掃描多個權重、不新增模型。以相同插件原始版本與九份凍結輸入建立隔離 baseline／candidate，分別記錄原版與唯一補丁後的 source/library hash；先確認新建 baseline 與快取逐事件一致，不一致先定位版本或字典差異，停止候選比較。

事前成功條件：Funk2 及至少兩份 HU33 的內部錯根音各相對降低至少 10%；九份每一份的 root 與 majmin accuracy 退步不得超過 1 個百分點，漏／多和弦增加不得超過 0.25s，邊界 precision／recall 退步不得超過 5 個百分點。逐來源列原值及差值；任何條件未達即否決此固定消融，不以調小權重／縮片段續試。這是研究篩選條件，非產品採用門檻。

資源上限建議單一工作段最多兩小時、九份各 baseline／candidate 一次、本機 CPU 循序、零外部 API／下載／付費；能重用同版中間聲學快取就重用。若編譯或基線一致性無法在上限內成立，交付缺失證據並停止，不擴成模型搜尋。即使通過，升共同設定前仍須另凍結至少兩份未用來改規則的確認來源，通過顧問工程／跨曲審查，才提出必要集中人耳驗收。本段不要求使用者試聽。

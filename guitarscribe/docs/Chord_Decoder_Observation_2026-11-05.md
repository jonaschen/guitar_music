2026-11-05，A12。九份來源各一次隔離觀測，全部歷史解碼輸出及投影事件與 A10 原版逐項一致（時間容差 1e-9）。本段新增觀測，不改產品／預設；沒有新的人耳驗收。

可嚴格表示的區間內，HMM 把局部錯誤轉為正確共 **47.782 秒**，反向損失 **6.626 秒**，兩者仍錯 **49.009 秒**。事前要求「損失大於救回」才提降低 self-transition 實驗，本次不符合，**停止這輪定位，不試調解碼、不新增字典、不再加一輪分類**。仍不能宣稱局部分數失敗就是純聲學根因，模板、正規化、競爭候選等都有作用。

## 固定觀測與工程閘門

[計畫](evaluation/chord-decoder-trace-plan-2026-11-05.json) 在執行前凍結，從 14:20:30 UTC 起算最多 90 分鐘、原九份來源每份最多一次，零外部 API／付費／下載；重用 A10 完全相同的正規化音訊及原始版本。完整 build、patch、來源、音訊與事件 hash 綁在 [數值證據](evaluation/chord-decoder-trace-results-2026-11-05.json)。原插件與現行服務沒有替換。

隔離插件保留每一實際 frame 的 sec/nsec、全部 217 個候選（含 N、重複標籤 profile）的字典 index／label／24 權重、原既有 N 調整及 cap 後、pow 前 salience、正規化 emission、第一個局部最大值、所有完全同分 index，以及原 HMM path index。沒有溫度補償、裁短和弦、重對齊或其他演算法修改。salience 可重建 emission，最大數值差小於 1e-10。

完整歷史 decoder 輸出（包含舊 padding／slash）及各來源原有 score 投影逐事件相同後，才解讀該 trace。九份皆通過；完整 Vamp raw_events 保存，歷史快取沒有的 N 原始事件不宣稱有真值。

## 時間加權結果

每個 frame 使用實際 timestamp 至下一個 timestamp，與原參考區間相交後以秒加權；最後 frame 不推測延長。未觀測覆蓋單列，不補造 frame。margin 為「最佳正確候選 emission − 最佳錯誤候選 emission」的時間加權平均；非機率校準或因果證明。下表單位秒，最後欄為 margin。

## 結論與具體剩餘缺口

本段排除了「直接降低共同 self-transition 就可修好」作為目前有支持的下一修改。沒有證據足以提出可靠的單一產品修正；現有原始候選在許多區間已選錯，字典又有混合缺席，改任一層都可能傷及既有控制。後續若要換聲學表示／引擎，需要另定可測方法與未用來改規則的確認來源；本段不啟動新模型搜尋，也不以更多分類延續這輪診斷。請顧問審查後決定產品優先順序。

三項新測試通過：不等寬 frame 必須按時間加權、最後 frame 不虛構覆蓋、缺完整種類時根音存在不能算可評，以及錯 argmax／未正規化 emission 拒絕。九份事件不變、salience 重建 emission、區間與四類秒數守恆均通過。

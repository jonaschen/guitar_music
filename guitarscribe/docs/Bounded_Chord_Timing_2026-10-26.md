# Codex：有界、可還原的換和弦時間候選

日期：2026-10-26。承接「A 約 22 秒不合、B 較合拍」的驗收。沒有繼續微調該片段，也沒有將最近拍點吸附套用到所有歌曲。

## 本輪完成

新增 `backend/app/services/chord_timing_candidate.py` 與兩個明確呼叫的 API。既有主 UI、來源選擇、正式 compiler、預設分析與資料庫內容不變。

- `POST /scores/chord-timing-candidate`：送入 score、start、end、downbeats_confirmed。未明確確認範圍內第一拍時回 409；產生只回傳候選／改動／略過原因，不套用或保存。
- `POST /scores/chord-timing-restore`：以保存的 receipt 還原原辨識邊界。和弦在套用後又有修改時拒絕覆蓋，保留人工工作；單獨修改旋律仍可還原和弦時間。

這是後端與工程產物，不宣稱使用者介面已加入時間修正按鈕。既有伴奏和弦候選入口也不會自動呼叫它。

## 固定規則與界線

政策 `late-downbeat-v1` 只檢查明確選用的伴奏來源和弦候選。只考慮指定範圍內、共享邊界的相鄰兩個不同和弦，且必須同時符合：

1. 邊界晚於小節第一拍，但差距不超過 **50ms 與當地一拍的 1/8 兩者較小值**。
2. 前後和弦原本皆至少維持當地一拍，且都不是人工編輯。
3. 該第一拍原本確實有一個前和弦的有效刷奏。
4. 新和弦原本要等待至少半拍才首次發聲。

只把符合條件的共用邊界往前移至這個已存在的第一拍。真正空白、短和弦、早進／明顯離拍、非第一拍、較大延後、人工修改、無刷奏的位置均略過。拒絕不合法範圍、重疊、重複 ID、非有限時間、亂序拍點；移動後也不能使事件塌縮。

50ms 是本輪明訂的工程限幅，不是估計器已校準誤差或音樂真值。合理的 20–40ms 延後仍可能被誤改，所以不聲稱能自動分辨所有切分／微時差，維持可選與人耳拍格前提，不建立全域規則。測試只能證明所列反例被保留。

原辨識時間與演奏時間以 receipt 分開記錄，包含每個左右和弦 ID、原邊界、新入口、原首刷、範圍、政策、原／候選和弦雜湊及拍格／刷奏型雜湊。保存重載後仍可還原。無改動時不新增 receipt；已有候選時拒絕重複累積修正。

## 已證實的結果

- 已驗收 10–40 秒：只改 **3 處**（原曲 27.8613、32.3413、36.8213 秒）。它們對應先前播放器 17.82、22.30、26.80 秒的三次刷奏歸屬差異。
- 在該 30 秒內，產生的吉他事件起訖、延音、音高、每弦 offset／velocity、刷奏方向，與使用者偏好的較廣吸附 B **逐項完全相同**。因此不用再要求使用者重聽。
- 原來源、拍點、旋律與有效刷奏起點／方向均保留；沒有重新辨識、分離或新模型。
- 既有第三來源 20 秒研究預覽找到 4 處；小手拉大手固定片段找到 1 處。這兩段的第一拍尚未獨立確認，所以這些只是工程預覽，未套用或宣布音樂品質過關。

Python 候選、伴奏候選與 MIDI 檢查合計 50 passed；後續補充拍格／節奏雜湊及既有 warning 還原保護，時間候選測試再通過 22 項。包括短事件、真實空白、提早／離拍、非第一拍、較快速度的相對限幅、人工修改、範圍保護、無有效刷奏、來源拒絕、存入臨時 SQLite 後重載還原、修改和弦後拒絕覆蓋。未把這些測試數當品質分數。

實際 localhost API 已驗證回傳 3 處、`applied=false`／`saved=false`，還原完整 score 與送入值一致。後端確認無活躍分析後更新；原 job／修訂未寫入。

## 投入與仍未知的事

本輪以既有 JSON、manifest 與 WAV 進行，不跑新辨識、分離或下載。工程工作未精確分項計時，低於本輪四小時上限；不捏造 token 或金額。尚未證明其他來源的第一拍正確、微時差都能安全修正或整曲皆適用。旋律問題保持未解決。

## 唯一下一步：第三來源拍格確認

既有第三來源原曲 20–40 秒，在生成前固定，沿用原有拍點，共 36 個 click；只加入 click，不改速或時間。入口：`http://localhost:5173/listening/third-source-click-2026-10-26/index.html`。

請使用者聽一次 20 秒，回答：click 是否合拍、是否半速／倍速、高音重拍是否像第一拍；無法判斷有效。這是另一來源的拍格確認，不是重測上一個已通過片段，也不需要新來源。

音檔 48kHz、20 秒，輸出峰值約 0.838，PCM 讀回誤差不超過一個量化單位；瀏覽器載入、播放與暫停檢查通過。聽感結果出來前，不將該來源的時間候選用到正式工作譜。

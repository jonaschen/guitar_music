# 歌曲大段、比較與沿用：交付紀錄

日期：2026-11-17。延續使用者「時間有限，希望先把功能及測試完成」的要求；交叉session協作，單一部署，沒有修改正式歌曲的根音判斷。

## 可使用的流程

主畫面 → 視覺化練習 → 分析歌曲結構／查看結構初稿 → 明確套用 → 挑一大段練根音 → 比較重複段與沿用 → 預覽並確認 → 結構譜／下次續練。

- 新歌分析為受限本機背景工作；進度、取消、重開、逾時與錯誤皆可處理。正式《可惜不是你》已備妥17段候選，兩個相同錄音job不必重跑。1032.78秒推論，初稿未冒充人工確認。
- 比較兩大段只播原錄音，關閉合成音與節拍；比較和停止後主控制重播都使用音訊SHA與來源fingerprint。
- 只有已保存的小節稿可沿用；先選完整等長核心並回聽確認。只填pending/null，保留已採用／再聽、未知、換音衝突與範圍外頭尾，不自動移調或重切。
- 套用與撤銷採單次SQLite交易，root／history／ledger一起提交或回滾。晚到預覽、舊版本與來源變動不覆寫；撤銷保留其他段後續修正，該批目標改過則不硬還原。
- 結構譜保留完整原曲順序、局部參照及不同結尾；只有完整相鄰有效關係才寫×N。跨交界的根音只裁展示時間，原決策ID／起訖保留；可以文字及JSON匯出。
- 已採用、待聽、再聽、預覽待核對、有效沿用各有數字。暫不練只記本瀏覽器偏好，未判斷仍未完成。

## 驗證與資料保護

新reuse後端29項＋既有root後端10項、原根音瀏覽器50項、新比較與匯出14項、真FastAPI／SQLite／瀏覽器2項及TypeScript／production build通過。數字按唯一案例分批計算，不把重試加成新測試。

隔離實際流程涵蓋原曲A/B、雙hash重播、選一格沿用、保留unsure、匯出、重開、另一處修改後整批撤銷，以及另一個client改來源根音後拒絕舊計畫。測試使用暫存24秒音訊與資料庫；音樂品質不由此推論。

programmer-session審查發現兩個問題並由partner-session修正：未保存／新版本等待ledger時不可匯出舊有效反覆；跨大段根音輸出不能重複整個時間區間。另補比較暫停後主播放須保留雙hash，均有回歸證據。

正式《沒那麼簡單》是初始v2、version0，尚未保存任何根音；畫面已補上先採用根音保存的提示與禁用。將其115 BPM初始稿複製到暫存DB後，7小節預覽全為source_unknown，沒有偽填或浮點對齊錯誤。

正式站檢查、六資料庫一致性與畫面證據在本機 `output/evaluation/root-reuse-2026-11-17/`；摘要見 [測試紀錄](evaluation/root-reuse-2026-11-17.json)。備份供程式回退，禁止用舊DB覆蓋後續使用者進度。

## 仍需音樂判斷的部分

名稱／邊界是可修正候選，沒有獨立全曲真值，不能承諾自動完整正確。固定拍格不能自行判斷變速、弱起與不同樂句是否對齊；比較核心須人工回聽確認。工程已完成不等於每首歌的主副歌、和聲及小節都已驗收。

沒有要求使用者重跑工程測試，也沒有聲稱實測整曲省時百分比。操作入口與最短步驟見 [使用說明](Song_Structure_User_Guide_2026-11-17.md)。

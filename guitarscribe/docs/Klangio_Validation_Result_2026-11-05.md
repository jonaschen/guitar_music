# Codex：Klangio 實測與下一步

## 結論

已實際完成9個工作（首批6個＋詞彙對照3個），沒有重跑拍點。只上傳原先同意的三段公開授權吉他，各15秒；主旋律、使用者歌曲與工作譜未上傳。使用者確認新註冊、沒有購買方案；沒有建立訂閱或付款，服務也未回覆付費／額度錯誤。帳戶餘額無法由API key取得，**不宣稱剩餘額度**。

Klangio不能當本案的自動真值裁判。拍子也出現半速與第一拍錯誤；增加和弦詞彙沒有解決事先指定的錯大／小調案例。依[事前規則](MVP_Experiment_and_Release_Plan_2026-11-05.md)停止此詞彙路線，不再逐曲調參或重送相同設定。這排除了「直接找另一個工具當答案」及「改成full詞彙即可修好此錯誤」兩個具體做法，沒有判定所有外部工具都無效。

## 評分與執行程式的修正

- `mir_eval.majmin`會排除power chords、部分減和弦或缺音和弦。現增加可評秒數、未評秒數及比例；高分不代表涵蓋全譜。Funk3的49.4%是可評28.6%時間內的分數，不是整段所有和弦正確率。
- 外部JSON沒有BPM欄位，不再把預設0算成100%速度誤差。原始拍點、第一拍、根音、majmin分數逐項證明不變；報告格式更新1.5，舊報告保留。
- 封包／音訊／下載結果均綁SHA256及本機job journal；這次六份評分輸入組合全部驗證通過。API key只從使用者指定私密檔讀取，未輸出或提交。
- POST前先建立紀錄，斷線或拒絕不自動重試；可恢復取得結果，不重建工作；重新執行命令不消耗重複工作。建立六個／三個工作、付費拒絕、逾時、檔案竄改及不同詞彙混用有自動測試。

原始產物：`output/evaluation/external-validation-run-2026-11-05/`。`results/`為首批，`full-results/`為唯一詞彙變因；`report-verified.json`及`full-report-verified.json`含來源綁定結果。完整clip資料不提交Git。

# 用自己的手機現場介紹 GuitarScribe

目的：由你登入自己的手機，現場向朋友展示「先看結構、聽一段、看低頻」；沿用目前歌曲與練習進度。

## 三分鐘介紹

1. 在手機開啟維護者提供的 **手機介紹連結**，輸入原有邀請帳密。原主畫面、視覺化練習頁及歌曲結構頁也有「手機介紹」入口，會帶入正在使用的歌曲。
2. **歌曲結構**：指出前奏、主歌、副歌等大段。點一段，再按「下一步：聽這一段」。可以說：「先選一個大段練習，不用一開始就填完一百多個根音區段。」
3. **聽一段**：按「播放選定段落」。需要反覆回聽時勾選「A–B 循環」；切換介紹步驟或段落會停播。
4. **看低頻**：按「產生低頻圖」。點圖定位時間，再分別按「游標設為 A（開始）」與「游標設為 B（結束）」，最後按「播放目前範圍」。也可左右拖曳選範圍。只有原曲聲音，不會混入採用的根音或和弦。
5. 完成後暫停，按「結束介紹，回到練習」。

介紹模式不提供採用、確認或保存功能。已保存的結構優先顯示；若只有完成的分析初稿，會明確標示「尚未套用」，展示本身不會套用它。正常練習頁仍可編輯；離開它前請等待保存完成。

## 出門前準備

- 建議先在手機登入、開啟想介紹的歌曲並產生低頻圖，保留該分頁。每次重新載入網頁都可能重新下載整首音訊；目前歌曲約數十 MB，請留意手機網路速度。
- 使用 HTTPS 外網入口，手機不必與電腦連同一個 Wi-Fi；電腦上的服務必須持續開啟、連網且不能休眠。
- 切換到其他 App、鎖屏或離開頁面時，介紹播放會暫停；回來後手動按播放。手機瀏覽器也可能回收背景分頁，需要重新載入。
- 「複製介紹連結」只複製目前歌曲的入口，不含帳密。這次是你自己的手機示範；所有登入者仍共用同一份資料，尚未提供朋友各自的帳號與進度。

原 ngrok 網址本月流量已用完；本次使用有原登入保護的 Cloudflare 臨時入口。目前網址與維運方式見 [手機連線維護紀錄](Mobile_Demo_Tunnel_2026-11-17.md)。臨時入口重啟後網址會變動，並非永久上線服務。

## 解讀畫面

名稱與邊界的確認狀態分開顯示。模型初稿不等於正確答案；低頻亮線可能來自基音、泛音或鼓聲。已採用根音圖只表示音級，沒有原錄音八度資訊；仍需配合耳朵核對。

工程測試採 Chromium 手機觸控模擬與正式服務連線檢查；尚未以實體 iPhone／Android 完成驗收，不能宣稱所有手機瀏覽器都已驗證。

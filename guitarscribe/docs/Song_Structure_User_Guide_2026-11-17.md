# 歌曲結構練習：使用說明

更新：2026-11-17。先整理前奏、主歌、副歌等大段，再選一段練根音。

## 從哪裡開始

原本主畫面按「視覺化練習」即可進入，已開啟歌曲會一起帶入。視覺化根音練習頁新增「歌曲大段」與「整理歌曲結構」。用原來的試用網址及帳密即可，不需要重新分析歌曲。

上述 localhost 連結供主機上的瀏覽器使用；從原有試用網址開啟時，在根音頁點「整理歌曲結構」即可。

《膽小鬼》已納入你的回饋：原第 1、2 段前奏合併；原第 8、9 段是副歌；原第 12 段暫定「收尾段（較接近主歌）」；原第 13、14 段尾奏名稱已確認。合併後目前共 13 段，編輯區仍標示原模型段號，方便對照。其餘名稱、所有外側邊界仍需核對。《沒那麼簡單》有 14 段初稿，尚待核對。

## 新換的歌曲

1. 完成原有選歌／分析後，從主畫面進入「視覺化練習」，按「分析歌曲結構」。
2. 結構頁按「分析歌曲結構」。目前主機完整歌曲約需 15–20 分鐘，可以離開頁面再回來；也可取消，已保存進度會保留。
3. 完成後先看大段初稿，必要時用「聽這段初稿」回聽。按「套用分析初稿」才保存，接著選一大段練根音。

《可惜不是你》目前兩個同錄音工作都已備妥 **17 段初稿**，直接按「查看結構初稿」即可，無須重跑或先填完138個細部根音區段。名稱與交界仍是待確認；相鄰同名段可以聽過後合併，不自動認定它們完全相同。

重新分析只建立另一份候選；「以初稿替換目前結構」才改稿，可復原。另一首正在分析時會提示稍候；中斷、逾時或來源不符時保留原稿並顯示原因。

## 最短練習流程

1. 點時間帶或左側的歌曲段落。
2. 按「聽這段」。拿不準起點／終點時，按「聽開始交界」或「聽結束交界」，會播放交界前後各約 3 秒。
3. 名稱正確就按「確認名稱」。需要修改時，選「段落類別」、必要時改顯示名稱，先按「套用名稱」。
4. 按「練這段根音」，回到原本的大型頻譜與根音練習。

結構頁回聽只有原曲，不加入合成根音或和弦。名稱、邊界可以分開確認，不必一次完成整首。

## 調整段落

| 要做的事 | 操作 |
| --- | --- |
| 移動兩段交界 | 改目前段落的開始或結束秒數，再按相應的「套用…交界」。左右兩段會一起調整，不留下空隙。 |
| 分成兩段 | 填「分開位置」，或先播放到分界按「使用播放位置」，再按「在此分開」。 |
| 合併誤切的段落 | 選前一段，按「與下一段合併」。暫留前一段名稱，之後可改。 |
| 撤回修改 | 按「復原」；需要恢復剛撤回的操作時按「重做」。本次開頁最多保留 50 步。 |
| 確認邊界 | 聽過起點與終點後按「確認這段邊界」。 |

改共用交界會使兩側邊界回到待確認；分開／合併後，新段的名稱與邊界都需重新確認。原模型標記保留在獨立紀錄中。整首開頭、結尾固定為錄音範圍；無法建立零長度、重疊或漏空的段落。

極短模型片段仍保留，例如《沒那麼簡單》的末端未判定片段。少於 0.1 秒時，使用「聽交界」核對，再決定是否合併，不必勉強單獨回聽。

## 根音練習會如何改變

「歌曲大段」選單只顯示與該大段交疊的根音區段，並把原曲 A–B 設為該段範圍。選「整首歌曲」即可展開原有全部區段；A–B 仍保留你的最後範圍，可按原有控制重新設定。

跨越歌曲交界的根音小段會完整保留，右側仍顯示實際採用範圍。選擇／查看結構不會把根音切短、刪除或複製。若從頻譜選到範圍外的根音小段，清單會回到整首，避免目前選取項消失。

這一步讓你一次只面對一大段。原有根音區段與進度仍完整存在；需要處理重複段時，展開「比較重複段與沿用」。同名段落不代表和聲完全相同。

## 重複段比較與沿用

1. 在根音頁展開「比較重複段與沿用」，選來源大段與目標大段，用「聽來源整段／聽目標整段」對照。這裡只播原曲，也會關閉節拍聲，不加入比較音；「停止比較播放」可隨時停下。
2. 先練好來源中的根音。若尚未使用小節分段，按「設定小節分段」，核對拍速與第一拍，再「預覽／套用」既有小節分段。**有拍格不代表拍子一定正確**，需要回聽確認；系統不自動把舊稿換成固定拍速。
3. 選兩段要對應的核心起點及共同小節數。畫面會列出不沿用的頭尾；弱起、加長、不同結尾留著另外練，不會改歌曲結構邊界。
4. 按「預覽可沿用位置」。只把來源已採用且整格同音的結果列為可沿用；來源未知／一格內換音，以及目標已採用或「再聽」的位置都不代填。
5. 回聽確認對應後，勾「我已回聽並確認…」，重新預覽，取消不想沿用的勾選，再按「沿用選取的 N 格」。

一次沿用是一筆完整保存，成功後普通復原歷程會清空；請使用「已保存的沿用 → 撤銷這批沿用」。此紀錄重開仍在，介面顯示最近200批；撤銷只影響該批目標，保留其他段後續修改。若該批目標後來已改過、被重切，或拍格／來源變動，便不直接撤銷覆蓋；可用根音備份與歷次保存核對。

來源之後修改不會同步改掉其他副歌，紀錄會標示「待重新比較」。不同調不能自動移調沿用；有不同換音位置時先手動細分目標，再預覽。比較範圍依按下確認時的原錄音秒數保存，之後改結構名稱／邊界不會挪動已沿用的根音。

## 結構譜、反覆與今天的範圍

「依原曲順序練習」保留每次出現，可點擊回聽、展開全部根音，或下載文字／JSON。只有已明確沿用、仍有效且涵蓋完整相鄰大段的關係才縮寫「×2」；相隔的副歌以各次出現與參照範圍表示。不同頭尾會另列，播放時間不壓縮。

跨大段的根音在譜式顯示／匯出中按交界分開顯示，JSON另外保留原根音ID及原起訖；原練習決定不重切。匯出含完整展開順序，屬閱讀資料，並非根音／結構備份的匯入格式。

工作量分為「已採用、待聽、再聽」，另外列出有效沿用與目前預覽待核對的格數。「暫不練」可先排除今天不想處理的大段，只保存在本瀏覽器；重開仍記住，可按「恢復練習」。暫不練、收合與未知都不算完成，跨邊界且未整格落在略過範圍的根音仍留在待聽數中。

## 保存、備份與換歌

套用修改後自動保存，離開前確認上方顯示「已保存」。每首歌的結構獨立保存，換歌或重開後會取回。結構與根音是兩份資料：此頁的「下載結構備份」只含結構，根音備份仍在根音練習頁。

「備份與歷次保存」可匯入同一來源的 JSON，或預覽最近 50 個舊保存版本。看到預覽後按「套用預覽」才會保存成新版本；不同錄音的備份會被拒絕。

離線時，已套用但尚未上傳的草稿保留於**目前分頁**，重新整理同一分頁可以恢復。關閉分頁、清除瀏覽器資料或瀏覽器不提供儲存時，不能保證草稿留存；請下載備份。兩個分頁各留自己的草稿，伺服器版本衝突時會停止保存，不默默覆蓋別頁。

遇到連線／版本問題，可先「下載原始草稿」；連線恢復後重試。若另一頁已修改，保留草稿後再「載入最新版本」，需要時匯入草稿預覽。錄音變動或遺失時停止編輯／回聽，已保存結構仍可下載。

## 目前的範圍

新歌可從結構頁按鈕分析，也可建立手動結構。主歌／副歌可比較，對應經確認後才能沿用。自動名稱仍是候選，尚未取得足以宣稱全曲正確的獨立參考；你的局部回饋會保留為人工修訂。

目前不需要你安排工程測試。保存、回復、競寫與資料保護已由自動測試核對，不需要你逐項重測。

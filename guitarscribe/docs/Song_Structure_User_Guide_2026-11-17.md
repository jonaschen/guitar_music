# 歌曲結構練習：使用說明

更新：2026-11-17。先整理前奏、主歌、副歌等大段，再選一段練根音。

上述 localhost 連結供主機上的瀏覽器使用；從原有試用網址開啟時，在根音頁點「整理歌曲結構」即可。

《膽小鬼》已納入你的回饋：原第 1、2 段前奏合併；原第 8、9 段是副歌；原第 12 段暫定「收尾段（較接近主歌）」；原第 13、14 段尾奏名稱已確認。合併後目前共 13 段，編輯區仍標示原模型段號，方便對照。其餘名稱、所有外側邊界仍需核對。《沒那麼簡單》有 14 段初稿，尚待核對。

## 最短練習流程

1. 點時間帶或左側的歌曲段落。
2. 按「聽這段」。拿不準起點／終點時，按「聽開始交界」或「聽結束交界」，會播放交界前後各約 3 秒。
3. 名稱正確就按「確認名稱」。需要修改時，選「段落類別」、必要時改顯示名稱，先按「套用名稱」。
4. 按「練這段根音」，回到原本的大型頻譜與根音練習。

結構頁回聽只有原曲，不加入合成根音或和弦。名稱、邊界可以分開確認，不必一次完成整首。

## 調整段落

| 要做的事 | 操作 |
| --- | --- |
| 移動兩段交界 | 改目前段落的開始或結束秒數，再按相應的「套用…交界」。左右兩段會一起調整，不留下空隙。 |
| 分成兩段 | 填「分開位置」，或先播放到分界按「使用播放位置」，再按「在此分開」。 |
| 合併誤切的段落 | 選前一段，按「與下一段合併」。暫留前一段名稱，之後可改。 |
| 撤回修改 | 按「復原」；需要恢復剛撤回的操作時按「重做」。本次開頁最多保留 50 步。 |
| 確認邊界 | 聽過起點與終點後按「確認這段邊界」。 |

改共用交界會使兩側邊界回到待確認；分開／合併後，新段的名稱與邊界都需重新確認。原模型標記保留在獨立紀錄中。整首開頭、結尾固定為錄音範圍；無法建立零長度、重疊或漏空的段落。

極短模型片段仍保留，例如《沒那麼簡單》的末端未判定片段。少於 0.1 秒時，使用「聽交界」核對，再決定是否合併，不必勉強單獨回聽。

## 根音練習會如何改變

「歌曲大段」選單只顯示與該大段交疊的根音區段，並把原曲 A–B 設為該段範圍。選「整首歌曲」即可展開原有全部區段；A–B 仍保留你的最後範圍，可按原有控制重新設定。

跨越歌曲交界的根音小段會完整保留，右側仍顯示實際採用範圍。選擇／查看結構不會把根音切短、刪除或複製。若從頻譜選到範圍外的根音小段，清單會回到整首，避免目前選取項消失。

這一步讓你一次只面對一大段。159／151 個原有根音區段與進度仍完整存在；跨副歌沿用根音尚未啟用，同名段落也不代表和聲完全相同。

## 保存、備份與換歌

套用修改後自動保存，離開前確認上方顯示「已保存」。每首歌的結構獨立保存，換歌或重開後會取回。結構與根音是兩份資料：此頁的「下載結構備份」只含結構，根音備份仍在根音練習頁。

「備份與歷次保存」可匯入同一來源的 JSON，或預覽最近 50 個舊保存版本。看到預覽後按「套用預覽」才會保存成新版本；不同錄音的備份會被拒絕。

離線時，已套用但尚未上傳的草稿保留於**目前分頁**，重新整理同一分頁可以恢復。關閉分頁、清除瀏覽器資料或瀏覽器不提供儲存時，不能保證草稿留存；請下載備份。兩個分頁各留自己的草稿，伺服器版本衝突時會停止保存，不默默覆蓋別頁。

遇到連線／版本問題，可先「下載原始草稿」；連線恢復後重試。若另一頁已修改，保留草稿後再「載入最新版本」，需要時匯入草稿預覽。錄音變動或遺失時停止編輯／回聽，已保存結構仍可下載。

## 目前的範圍

目前兩首既有歌曲已接入可修正的模型初稿；新歌可建立手動結構。新歌的一鍵自動結構分析尚未接入主分析流程。自動名稱仍是候選，尚未取得足以宣稱全曲正確的獨立參考；你的局部回饋會保留為人工修訂。

晚上有空時，先用你正在練的一段，看看「選大段 → 聽交界／改名 → 練根音」是否順手即可。保存、回復、競寫與資料保護已由自動測試核對，不需要你逐項重測。

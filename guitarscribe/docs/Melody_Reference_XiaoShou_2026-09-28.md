## 保存結果的客觀問題

- 引擎 Basic Pitch，vocal 模式，但沒有分離來源；不能將 vocal 模式當作已取得人聲。
- 最終旋律 419 個事件；事件聯集 240.257 秒，其中 25.710 秒有重疊，最多同時 3 個事件。這是音符區間統計，不是合成 release tail。

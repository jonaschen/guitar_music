# 根音練習：手動節拍與小節對齊

使用者以節拍器115 BPM聽到拍子吻合，要求依BPM得到小節長度，並能從歌曲任意位置平移小節對齊點。

## 計畫與檢驗

每拍60/BPM秒，每小節為每拍長度乘每小節拍數。預設115 BPM、4拍只是可修改的起始設定，不宣稱自動辨識拍號。固定速度格線由一個手動小節起點向前後延伸；拖動或微調起點改變整首格線相位，改BPM改變間距。不能只把格線加在標記點之後，也不能把任何播放位置強制當歌曲第1小節。首尾不足一小節需顯示裁切，不假裝完整。

功能：BPM（20–300）、每小節節拍器拍數（1–12）、實際小節秒數；全曲定位滑桿；目前播放位置設小節起點；對齊點秒數與前／後10ms、前／後一拍；附近小節與拍點可視化，點小節設定既有A/B播放範圍。同步節拍聲預設關閉，強拍與弱拍可區分，與原曲共用音訊時鐘，暫停、續播、跨循環保持相同格線相位；播放中改格線只更新節拍，不重啟原曲。允許設定自訂長度的A/B，格線不強迫吸附。

視覺沿用現有練習頁：白#fff背景、文字#203345、輔助#526477、操作藍#185a9d、拍格線#cbd5de；既有字型與16px內文、14px輔助。主視覺是具有拍刻度的水平小節尺，其他控制左對齊；手機控制換行且觸控區至少44px。範圍區前直接呈現節拍與對齊，不藏在進階選單。

反思：BPM準確不代表知道第1拍，故間距與對齊點必須分開控制。小節格線與原來不等長的和聲區段含義不同；調格線不重切、清空或移動已採用根音。格線只協助定位與選取播放，小節內既有根音仍照其原時間發聲。這個固定BPM版本不處理錄音速度漸變／變拍；若後段漂移可修正BPM，不能承諾只平移就修好速度誤差。

保存：按歌曲來源指紋保存於本機瀏覽器localStorage，重開可恢復，與共用根音稿分開；UI說明保存位置，避免誤認跨裝置同步。設定變更不寫score或根音API，不讓預設值覆寫已有設定。同步節拍聲不自動發聲，須由使用者播放歌曲。

驗證：115 BPM及其他拍數數學、任意遠端對齊點向前後延伸、頭尾裁切、整體平移不改間距、空值／超界輸入；真WebAudio節拍起音與原曲時鐘比對、強弱拍、非拍點續播與非整小節循環、播放中改對齊不重啟原曲；設定恢復、四尺寸、已採用根音／原譜零改稿。完成後build並更新原受邀入口，真曲唯讀驗證。

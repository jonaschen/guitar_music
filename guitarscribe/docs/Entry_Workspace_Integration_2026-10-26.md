# Codex：演奏方案接回工作區

日期：2026-10-26。功能與自動檢查完成，待一次人類操作驗收。

## 使用者可見行為

工作區頂部新增「伴奏演奏」，從預設專注模式直接展開並定位到既有 Compiled score playback 區域，不必自行尋找完整工具。

「吉他演奏」可選原版、換和弦即彈的連續刷奏、換和弦只彈一下；預設維持原版。Play score／編輯器的吉他試聽與 Download MIDI 使用同一模式。「回原版演奏」立即停止舊合成排程並回原版。

模式是暫時的播放設定，不加入 SongScore、保存修訂、JSON 或 MusicXML。改譜（包含 Undo／Redo）、載入版本或刷新後回到原版，介面已說明。這個選擇避免舊譜在未確認下永久換成實驗方案；未來是否保存模式是獨立產品決策。

預覽成功後顯示已處理和弦段數及保留原演奏段數。MIDI 匯出區顯示目前模式，實驗版檔名帶 continuous／sparse。MIDI 不使用瀏覽器合成音色，不能用它驗收 Web Audio 的尾音。

## 避免舊結果誤用

- 切換模式會停止現有播放，讓舊的非同步預覽失效。
- 改譜與載入沿用工作譜世代檢查；舊 MIDI 請求完成後不下載。
- MIDI 匯出中停用重複按鈕，錯誤顯示在頁面；不再放任未處理的匯出例外。
- 後端不自動套用時間吸附；演奏模式忠於目前工作譜保存的邊界，不能自行糾正錯誤的和弦或拍點。

## 自動檢查

新增五項 Playwright 測試：播放／MIDI 同模式、切回原版／重載、晚回預覽失效、晚回 MIDI 取消與錯誤顯示、改譜／Undo 失效、專注模式直接入口（部分涵蓋於同一項）。既有 11 項 score-workspace 回歸亦通過。正式前端 build 通過；大型 alphaTab bundle 提示仍為既有建置警告。

本機後端確認沒有 queued／running 工作後更新。真實後端＋瀏覽器以獨立保存修訂測試：入口可見、播放／暫停、MIDI HTTP 200 與相同 playback revision、回原版及無頁面 JS 錯誤。新的功能不只停留在 mock。

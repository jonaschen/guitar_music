# 鎖定主歌／副歌，對照低頻填寫和弦

使用者需求：「鎖定某一段已經辨認完成的主歌或副歌，產生低頻圖以及填寫或修改和弦」。鎖定的意義是固定練習範圍；不是禁止日後整理歌曲結構。

## 2026-11-21 新增：先比較再沿用完整和弦

此擴充已通過本機真API與WebKit測試，雲端發布狀態以 Remaining_Stories_2026-11-21.md 為準。

1. 鎖定**要填入的目標段落**，展開「沿用其他段的和弦」。
2. 選已經填好和弦的來源段落。填來源核心 A／B 與目標核心 A；目標 B 自動保持相同長度。不同尾句留在核心之外。
3. 按「聽來源核心」「聽目標核心」比較原曲。這兩個比較按鈕可暫時回聽來源段，不改變目前鎖定的編輯範圍。播放只用同一個原曲播放器，沒有新增和弦聲音。
4. 確認對齊後勾選確認欄，按「預覽可沿用和弦」。來源已確認且目標待聽的切片可勾選；目標已填的、來源未定的會保留。
5. 檢查後按「套用勾選和弦」。C/E、Am7 等完整名稱及明確 N.C. 都可沿用，原分析參考保持不變。沒有自動伸縮節奏或移調。
6. 「沿用紀錄」可**復原這批沿用**，重開頁面仍可操作。若本批目標內容之後又有修改，改以手動核對，避免抹掉新進度。其他位置的修改不因復原而消失。

每次換來源、範圍或和弦版本都要重新預覽；未保存時不能批次沿用。斷線導致結果不明時先載入最新版本看紀錄，不盲目重送。一般「復原和弦修改」處理手動編輯；批次沿用使用自己的紀錄復原。

故事地圖延伸：**完成來源短句 → 鎖定另一段 → 比較兩段原曲 → 選共同核心 → 預覽 → 勾選套用 → 重開／復原**。名稱相同不代表和聲必然相同，不能只憑「副歌」標籤自動填滿。

## 操作說明

1. 在「整理歌曲結構」選好一段，等現有編輯顯示「已保存」，按 **鎖定這段練和弦**。視覺化練習的「歌曲大段」旁也有入口；主畫面可按「選段練和弦」。
2. 確認上方顯示 **已鎖定：主歌／副歌** 與時間範圍，按 **產生低頻圖**。所有縮放最多只看這段；「看整段」恢復完整鎖定範圍。
3. 按 **播放原曲範圍**，可勾選 A–B 循環。圖上點選移動游標，拖曳或分別設定 A／B 圈選範圍。也可在右方精確填秒數，秒數沿用本錄音片段，不會重設成每段從零開始。
4. 點右方一個和弦區段，輸入名稱，再按 **採用／更新和弦**。或者先圈選 A–B，再填這個範圍的和弦；範圍跨過多個原分析區段時，採用會涵蓋該範圍，但各自原分析參考保留。
5. **標記無和弦 N.C.** 是明確的聽辨結論；**清除為待聽** 則移除這個範圍的採用。根音不會自動推定成大三和弦。
6. 等 **已保存** 後可離開；下次仍載入同曲和弦練習稿。可用 **復原和弦修改／重做和弦修改**。換段時按 **解除鎖定／換段**；未保存或有衝突時先處理草稿。

原分析只作線索，「我的和弦」是自己的聽辨稿。保存於同首歌的和弦練習資料，獨立於根音與舊工作譜；目前不自動生成吉他伴奏或改寫舊工作譜。回聽沒有加入人工和弦、根音或節拍聲。低頻亮線仍可能是泛音／鼓聲，不代表和弦答案。

## 保存與來源保護

- 採用後自動保存，完整和弦 JSON 可下載。離線／保存失敗時保留本分頁與 sessionStorage 草稿，重試不重分析；若瀏覽器禁止本機儲存，仍可保存至服務端，離線時請下載備份。
- 另一分頁更新和弦、原曲變動、結構合併或移界，會停止保存並保留草稿。先下載需要保留的內容，再「載入最新版本」重選段落。不要把舊秒數直接搬到不同音訊。
- 跨界和弦只修改鎖定段內交集；段外和聲與原分析資料保留。復原回貼該段的先前和弦，為保護段外進度而留下的切割點可能保留。
- 修改段落名稱本身也會增加結構版本；正在鎖定練習的舊頁需要重新載入選段。鎖定不會替使用者確認名稱或邊界。
- 低頻只計算鎖定時間，但首次仍會載入與解碼整首原曲。裁切邊緣的分析窗有零填補；邊界附近的線條應配合回聽判斷。

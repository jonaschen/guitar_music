## 日常使用

[開啟既有《小手拉大手》和弦工作譜](http://localhost:5173/?revision=bc41b274-69d4-430f-8dda-52bd0759119d&view=accompaniment)。此網址依賴本機資料庫，換電腦須帶上資料。

1. 在「和弦核對」選起始小節與小節數，需要時勾選循環。
2. 選「原曲＋系統吉他」，按「從這段開頭播放」；可單聽原曲或吉他、調整吉他音量。
3. 修譜或匯出請按「顯示完整工具」。改動後保存並保留修訂網址。「還原上一步」處理本次工作階段修改；重載後不保留 Undo 歷史，已保存修訂可用原網址重開。
4. 完整工具可匯出 JSON、MIDI、MusicXML、ChordPro。MIDI 可能含實驗旋律，原曲混音不寫入 MIDI；演奏選項影響 MIDI，JSON／MusicXML 保留譜面資料。

新瀏覽器預設簡潔和弦頁，明確切換旋律頁會記住偏好；網址 `view=accompaniment` 或 `view=melody` 優先。既有完整工具偏好保留。歷史試聽頁已標記完成，無須重新提交。

## 本機啟動

目前環境已有依賴與模型。服務已執行時不用重啟；以下不是全新電腦安裝程序。

後端終端：

```bash
cd /home/jonas/gemini-home/music_analysis
bash guitarscribe/backend/scripts/run_local_preview.sh
```

前端另開終端：

```bash
cd /home/jonas/gemini-home/music_analysis/guitarscribe/frontend
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

開啟 http://localhost:5173 。健康檢查 `curl http://127.0.0.1:8000/health` 預期回傳 `{"status":"ok"}`。本機分析不需要外部轉譜 API；YouTube 下載及首次模型安裝仍可能需要網路。

## 資料保存

Git 不等於音訊與修訂備份。下列相對路徑以 `guitarscribe/` 為根：

- `output/work/jobs/jobs.sqlite3`：工作記錄。
- `output/work/jobs/<job-id>/`：來源音訊、分離音軌等。
- `output/work/revisions/guitarscribe.sqlite3`：保存修訂。
- `output/evaluation/`、`frontend/public/listening/`：本機實驗及試聽產物。
- `~/.cache/guitarscribe-runtime/` 及模型快取：本機依賴。

搬移時保存完整 `output/work/` 及所需本機產物，只帶修訂資料庫無法恢復原曲播放。安全備份與還原見 [OPERATIONS.md](OPERATIONS.md)。本輪沒有刪除資料，也沒有另行完成備份。

# 隨歌曲保存的文字旋律筆記

使用者要求記下自己抓的旋律，為未來功能留入口。本次新增可收合的「我的旋律筆記」，接受純文字調性／音名／片段，不建立音符編輯器，不啟用自動旋律，也不把使用者猜的G當成辨識真值。

筆記由source job獨立存入伺服器 `work/melody-notes.sqlite3`，不放SongScore或和弦revisions。因此和弦Undo、還原原分析、載入歷史稿及移調不會刪除／轉調手記。保存以expected_version做SQLite原子CAS，別的瀏覽器先更新時回409，保留自己的文字並要求明確載入最新版本，不能默默覆寫。

輸入後700ms自動保存，另有立即保存／失敗重試。狀態用「正在保存／已保存／保存失敗，文字仍保留」等白話。每首來源有獨立保存佇列，切歌後舊保存只回舊來源；過期載入會取消，StrictMode重訂閱會重建已取消的讀取。草稿按source存在每個分頁自己的sessionStorage，重載可復原，另一tab成功保存不會刪掉本tab未存文字。分頁關閉不保證未存草稿仍在；跨裝置依伺服器已保存版本。此邀請空間共用，不是私人帳號。

衝突後刷新仍保留原baseVersion，避免下一次刷新把本地字誤當可直接寫入的新版。載入失敗也能看到並編輯該分頁草稿；未知網路／JSON錯誤一律中文，不外露Failed to fetch。明確確認後載入伺服器版本才取代未存字。文字以textarea呈現，不解析HTML，不介入播放／匯出。

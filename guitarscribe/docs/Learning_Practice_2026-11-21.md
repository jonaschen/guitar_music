# 主音假設與和弦組成音比較

本輪新增的學習工具先在本機驗證，尚未部署至個人雲端。這些工具可跳過，不會要求先答對調性才能練習。

## 操作

1. 在視覺化根音練習或已鎖定的段落和弦頁，展開「主音與調式假設」。尚未指定時保留未定，不預設 C 大調。
2. 選主音與大調／小調／未定／其他，寫自己的判斷。「把目前 A–B 記為依據」記錄錄音秒數，可另寫聽到什麼。按「採用並保存調性假設」才寫入伺服器。
3. 若只想記局部的中心，勾「只記目前這段錄音的假設」。開始編輯時固定該範圍；之後移動 A–B 不會偷偷移動假設。已保存局部假設可從下方時間按鈕重開。全曲和局部互不覆蓋，結構合併不會刪掉時間依據。
4. 在段落和弦頁展開「比較和弦組成音」，填兩個候選，例如 G 與 Gm，查看 B／Bb 的差異。C/E 分別顯示根音 C 與低音 E；同音級集合也不代表相同和弦或功能。
5. 參考聲預設關閉。明確勾選後可以逐音或合奏；原曲先暫停。恢復原曲、切換範圍、背景／離開頁面會停止參考聲。參考聲是固定示範音域，不代表錄音的八度與配器。
6. 展開「錄音音級線索」，選 0.5–30 秒 A–B 後按讀取。十二條能量是該錄音範圍的 STFT 頻率能量，0 dB 表示當段最強音級；不是機率、確定音符或和弦推薦。人聲、泛音與打擊聲會混入，靜音明示不足，改範圍會清掉舊結果。
7. 「填入候選」只改和弦欄位；仍須按原有「採用／更新和弦」保存。調性假設不移調原音、不限制調外音，也不改寫已採用根音或和弦。

8. 採用和弦時另記當下重疊根音與段落交界；之後改根音、分段或合併會顯示「請重聽後重新採用」，不刪除和弦。點該和弦、回聽並再次採用即可記錄新依據。舊稿與沿用稿沒有紀錄時顯示未知；復原舊判斷保留其原依據，不假稱已確認。只改段落名稱不使和聲失效。

## 保存與失敗處理

學習筆記獨立保存在 `learning-practice.sqlite3`，綁定分析指紋、錄音 SHA、來源起點與長度，具有版本比較及歷史。既有整份 work 備份會包含它。展開讀取未保存的歌曲不建立空資料庫。

未採用草稿暫存在各分頁 sessionStorage。另一頁已更新、來源改變、保存回覆丟失時停止再送，保留本頁草稿；先複製需要的內容，再按「載入最新學習筆記」。瀏覽器停用暫存時不可承諾草稿跨重載保留，仍可保存到伺服器。這裡的個人採用不是獨立標註或訓練真值。

## 驗證與界線

- TDD 先確認缺少資料模組／理論模組／畫面時失敗，再完成實作。
- 9 項後端測試：範圍、重複 ID、未定、局部／全曲、歷史、來源遺失、交易內來源重查、版本衝突及無寫入 GET。
- 3 項音樂字典測試：正確音名拼寫、七和弦／sus／無三音、轉位、同音集合不同根音、關係大小調。
- Chromium 的核心 3 項、Linux WebKit 的完整 4 項真 API 整合測試：保存／重開／雙頁衝突／已提交但回覆丟失、草稿恢復、來源稿不變、參考聲與原曲互斥、停止逐音、390px 無溢出。不是實體 iPhone 驗證。
- 根音／交界依據、和弦保存及沿用共 73 項後端回歸通過；音級能量與假設共 16 項通過，合計 89 項。合成音驗證大／小三和弦差異、靜音、反相立體聲、和弦外旋律；不等於真實混音的和弦準確率。
- 能量採 22050 Hz、8192 點 Hann STFT、2048 hop、C2–C7 頻帶折合音級，左右聲道各算功率後平均，避免反相抵消；只讀所選區間。它不排名或自動採用和弦，也不把原根音分數冒稱新的聲學證據。舊設計中的自動候選排序與羅馬數字解釋未在本輪啟用；現階段以可核對的手動比較完成練習主線。

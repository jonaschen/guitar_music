# 旋律人工修譜：第一個測試 checkpoint

本次測試的是「能否把錯誤初稿修成想要的音符」，不是再次驗收自動旋律辨識。現有分析可直接使用，不必重跑人聲分離或全曲分析。

## 建議測試（約 5–10 分鐘）

1. 重新整理 Web UI，載入《小手拉大手》的現有分析，展開 **旋律人工編輯 · Melody editor**。
2. 將「片段起點（秒）」設為 `26`，先聽原曲／Contour 作參考，再按「試聽修訂片段」。後者只播放工作樂譜的旋律，沒有吉他伴奏。
3. 選一個音符，改音高或八度、起點／終點，按 **Apply note**。再試聽修訂片段，確認聽到修改。可先故意升高八度作容易辨識的測試，再 Undo。
4. 測試 **Undo melody edit / Redo melody edit**。這與和弦編輯共用整份樂譜歷史，不是另一套旋律專用歷史。
5. 找一段空白，按 **New at playhead**，填入音高與起迄秒數，再按 **Add note**。試 **Delete note** 並 Undo。不能與其他音符重疊；需要先縮短或刪除衝突音符，不會自動覆蓋。
6. 按 **Save new revision**，記下版本 ID。重新整理後，版本 ID 會自動帶回，但預設仍顯示原分析；按 **Load melody revision** 載入保存的修訂，確認音符仍在。未保存修改不保留。
7. 匯出 MIDI／MusicXML，或打開 Tab，確認修改的音高／時間已反映。選用：將播放位置移到已保存音符內部，再 **Split at playhead**；相接且同音高才能 **Merge next same pitch**。

## 請回報

- 能否選到想改的音符？起迄秒數是否容易調整？
- 修訂片段是否確實播放修改後的音高及長度？Undo／保存／重載是否正常？
- 若失敗，提供片段秒數、操作、訊息或截圖。不需要先修完整首歌。

## 邊界與下一步

- Original／Vocal contour 是不變的來源對照；**改譜後請聽修訂片段或 Play score，不要用 Contour 判斷修改是否生效**。
- 目前按秒數精確編輯，不自動吸附尚未可靠的拍點；不是完整五線譜／鋼琴卷軸編輯器。
- 新音符人工來源不會使模型信心變成 1。無可用吉他把位時保留音高並提示，不偷偷改音。
- MusicXML 已修正跨小節音長及弱起音符遺失；任意時值的完整節奏記譜仍待改善。
- 自動初稿仍有錯音及器樂段落缺漏。這次没有改善自動辨識，也没有用修正訓練模型。
- 接下來依本輪操作回饋改善修譜成本，再加入修正意圖／確認／鎖定與可比較的局部重分析。

# 根音練習使用者故事與故事地圖

本輪整理現有根音工作區的操作，目標是讓使用者能清楚知道正在聽哪裡、正在判斷哪段、何時會加入參考音，以及何時會保存。使用者暫時無法測試，工程驗收由代理完成；主觀易用性另記，不作為停止可驗證工作的理由。

## 使用者故事清單

| ID | 使用者故事 | 可驗證的完成條件 |
| --- | --- | --- |
| US1 | 身為抓歌練習者，我要一直看得到目前要記錄的段落，避免把判斷填到另一段。 | 採用鈕旁常駐段落與起訖；播放位置、A–B 改變不暗改採用目標；只有明確選段才換目標。 |
| US2 | 我在低頻圖找到想練的地方後，要能直接開始該段練習。 | 「練習游標所在段」選取既有段落、對齊回聽範圍、停止舊音並清除未採用試音；不重切或寫稿。跨段拖曳不批次採用。 |
| US3 | 我想先專心聽原曲，需要時才比較參考音。 | 主要播放預設原曲、顯示範圍與聲音；暫停續播不偷偷加音；明確點音名才試音；成果連聽清楚標示含已採用根音。 |
| US4 | 我想連續練習，不想一直在長頁面尋找播放與採用。 | 主要畫面集中目前段落、播放、頻譜、比較與採用；桌面並排、手機順序一致；下一段不帶入未採用候選、不自動保存。 |
| US5 | 我偶爾需要調拍格、切段與精確秒數，平常不想先處理設定。 | 工具預設折收但保留功能與狀態；折收不卸載音訊或頻譜；未套用拍格與保存衝突仍在主畫面提示。 |
| US6 | 我想放心試、保留不確定，之後繼續練習。 | 採用只寫目標段；待聽、復原、保存、重開、衝突與備份仍可用；完整使用說明與失敗排錯可查。 |

## 排序代辦與 TDD

| 順序 | 任務 | 故事 | 狀態 | Red → Green 驗收 |
| --- | --- | --- | --- | --- |
| T1 | 固定採用目標及圖上明確進入段落 | US1、US2 | done | 新流程測試先重現目標不明與缺選段入口；實作後驗只寫選中段、跨段拖曳零寫入。 |
| T2 | 共用主要原曲播放與明示模式 | US3 | done | 驗預設短段、原曲零合成音、比較後可停止、續播模式相同；保留原有發聲檢查。 |
| T3 | 主畫面與進階工具重整 | US4、US5 | done | 驗初始工具折收、主要控制可見；四尺寸、鍵盤、收合後播放與資料不變；拍格阻塞仍可見。 |
| T4 | 連續採用、待聽、下一段及恢復 | US4、US6 | done | 驗完整兩段練習、未採用試音不帶入、精確寫入與復原／重開；既有離線／衝突回歸。 |
| T5 | 正式兩曲唯讀驗證、手冊、交接與發布 | 全部 | done | 完整相關測試、TypeScript／build、兩真曲四尺寸、無非預期寫入；保留回退與舊入口。 |

每項先跑新增失敗案例，再作最小實作、重跑通過，最後整理重複狀態與控制。保存測試使用隔離資料；正式歌曲只讀。T1–T5 全部完成才結束這輪，不能以「等待使用者試用」代替工程工作。

## 版面與操作約定

沿用現有白底 #ffffff、文字 #203345、輔助文字 #526477、操作藍 #185a9d、頻譜青 #267b85；沿用系統字型，文字左對齊。頻譜是主要音樂線索，操作保持簡單，不新增裝飾性圖像。

```text
歌曲與保存狀態
根音區段列
目前判斷的段落與回聽範圍 ｜ 主要播放、暫停、聲音狀態
低頻圖／定位與選段       ｜ 比較音、採用目標、採用／待聽、上一段／下一段
                         （手機改為上下排列）
復原／成果回顧
練習設定與進階工具（預設折收）
歷次保存／備份
```

播放位置、回聽範圍、採用目標是不同資訊：一起顯示並提供明確連接動作，不能為了看似統一就讓自由選取偷偷切段或批次改稿。單純採用不自動跳下一段。錯誤、保存衝突及未套用拍格的阻塞提示不得藏進折收區。

本輪不新增自動音樂模型，也不把原三階段計畫中尚未實作的調性／和弦組成音功能列成已完成。工程結果與主觀易用性分開記錄。

## 執行結果

實作前：已由 programmer-session 唯讀確認上述狀態問題及排序；她暫不修改重疊檔案。前置的「低頻播放只聽原曲」已完成 30 項回歸與兩首正式真音訊檢查，各只啟動 1 個原曲來源、0 個合成振盪器；本輪新流程將另外驗收。

第一輪 T1–T4：新增五個使用流程測試先失敗，實作後全部通過，TypeScript 通過。工具折收測試最初使用不合法的 null matcher，修正後重新確認缺少介面導致失敗，再進入實作；未把測試程式錯誤當產品重現。整合驗證仍由 T5 追蹤。

T5 唯讀審查補強亦依 Red → Green 執行：歷史恢復預覽藏於折收區、實際播放範圍未顯示、主要播放覆寫循環偏好、手機播放鍵離開視窗、已採用根音誤標比較音、節拍聲開啟後標示遺漏。每項都先以瀏覽器重現，再修正對應狀態／版面；保存與模型語義沒有為了通過測試而放寬。主要播放器改為吸頂，工具折收不卸載播放器與頻譜。中途完整 35 項、39 項回歸已通過；最終數字與發布核對另記於驗證摘要。


## 最終交付

T1–T5 全部完成，六則故事的工程驗收通過。41 項完整根音回歸、TypeScript、production build 通過；目視檢查後再將游標資訊明確標為「播放游標」，相關目標／保存測試再次通過。兩首真音訊的最終建置均完成四尺寸檢查、明確選段、跨段 A–B、播放器前進、工具折收不中斷來源、手機採用鍵與吸頂播放器不遮擋。每首只啟動 1 個原曲音訊來源、0 個合成振盪器，原 Score 與根音稿保持相同，0 頁面例外／非預期寫入。166 個其他網站檔案不變，服務未重啟。

首次正式操作腳本沿用選段前座標而拖曳未命中；修正為選段後將圖表置中、重讀座標再操作，最後兩曲通過。這是腳本修正，不放寬產品的時間或資料斷言。

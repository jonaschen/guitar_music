# 和弦試聽 checkpoint · 2026-09-25

## 最新補測：只確認播放連續性，不要求辨識和弦

已修正 guitar-only 無聲，以及每個和弦區段重新刷奏造成的短促重複聲。既有 job 在下一次 `Play score`／MIDI 匯出時即使用新版編譯器，不需要重新分析。

1. 重新整理頁面，按 `Stop score`，只開 guitar、取消其他 Solo、音量約一半。
2. 先選 Simple Quarter Note Strum（若尚未選），按 `Play score` 聽 15–30 秒：是否由不規則的短促跳音變成較規律的撥弦？吉他每下自然衰減是預期效果，不要求像持續的風琴聲。
3. 若想比較原曲，先暫停合成播放，點擊一個和弦記住秒數，選 `Original` 後按 `Play`。再暫停原曲，點同一和弦，按 `Play score`，比較同一段。兩者不是同時播放。
4. 回報「較規律／仍亂跳／有大片無聲」和出問題秒數即可；不需要判斷和弦名稱或曲子是否能被辨認。

吉他軌目前是依偵測和弦與拍點產生的建議伴奏，不是擷取原曲吉他，也不是完整編曲。沒有落在模板刷奏點的短和弦可能不發聲；原始和弦仍保留於畫面與 JSON。此補測不代表和弦／拍點品質通過。

目的：檢查保全 decoder 事件及 N.C. 後，和弦草稿是否更忠實於原曲。不是主旋律驗收，也不是已完成 timing／chord engine bake-off。

## 三項測試（約 10 分鐘）

1. **原曲與拍點**：選 `Original`，按 `Play`，開啟 `Metronome`，聽連續 8–16 小節。記錄重拍是否自然、換和弦是否過早／過晚、是否越播越偏；先不要用校正按鈕掩蓋問題。
2. **和弦與空隙**：切換 `Play score`，只勾選 `guitar`（關閉 `melody` 與 `metronome`，確認沒有其他軌 Solo）。比較同一段的和弦走向。N.C. 虛線塊只表示「未配置和弦」，不保證原曲無和弦；若原曲明明有伴奏，請記錄為漏抓。N.C. 期間不應有新的吉他撥弦，但合成音色可能有短尾音。
3. **小節定位**：點擊 N.C. 應跳到其起點；點擊下一小節的 `Continues` 和弦應跳到該小節顯示起點，而非回到上一小節。確認和弦卡片順序與顯示時間一致。若這首沒有空隙或跨小節和弦，該項記為不適用，不必刻意尋找。

## 回報格式

- 使用片段、job ID（網址中的 `job=`）與匯出的 JSON。
- 問題時間／小節，例如「12.4–14.0 秒，Bar 7」。
- 類型：和弦錯誤／換和弦過早或過晚／N.C. 漏抓／重拍不對／越播越偏／UI 定位。
- 若知道正確和弦或拍點可一起提供，不知道也沒關係。
- 整體：是否可跟著伴奏？大約要修改幾處？

本輪自動檢查只證明資料保全與程式行為，不能證明歌曲辨識、和弦準確率或音樂品質 gate 已通過。收到回報後，先將可授權片段轉成核對過的 baseline 標註，再進行 timing／chord 候選引擎比較。

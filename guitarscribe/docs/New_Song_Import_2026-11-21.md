# 換歌與 YouTube 無法下載時的操作

先確認目前練習稿顯示「已保存」，再從主畫面的新曲目入口加入歌曲。已存的歌可從雲端頂端「我的歌曲」重新開啟。

YouTube 若要求機器人驗證或拒絕下載，這首新歌尚未成功匯入；已保存的其他歌不受影響。改選你有權使用的音檔即可：**選擇音檔會清除殘留網址**，下一次「開始分析」會上傳音檔；再次填網址則改用 YouTube。分析服務未啟用 YouTube 時也能走音檔上傳。

本次修正已用受控服務回應驗證「YouTube 拒絕→改選音檔→分析完成→保存版本→重新開啟」。音訊實際分析／雲端上傳沿用既有已驗證管線；沒有宣稱能繞過 YouTube 的來源限制。發布狀態見 Remaining_Stories_2026-11-21.md。
